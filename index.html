备份与恢复

本机数据概况

一、创建备份

将账单、分类配置、商户规则、退款关联及导入历史等本应用数据导出为 JSON 文件，保存到手机或云端文件夹。

二、从备份恢复

选择本应用生成的 JSON 备份文件。可选择完整覆盖恢复，或仅补入备份中尚不存在的账单。恢复前建议先下载当前数据备份。

重要：数据目前保存在当前浏览器本机。备份文件需要由你自行保存；卸载浏览器、清除网站数据或更换设备前，请先备份。此功能不会把数据上传到服务器。
